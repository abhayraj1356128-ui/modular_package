# Moduler Packager

A simple Python command-line utility that demonstrates commonly used modules in Python, including `datetime`, `math`, `random`, `uuid`, and basic file operations.

## Features

- Date and time utilities
  - current date and time
  - difference between two dates
  - custom date formatting
  - stopwatch
  - countdown timer
- Math operations
  - square root
  - factorial
  - power calculation
  - ceiling and floor functions
- Random module features
  - random integer
  - random list/sample
  - random password generator
  - OTP generator
  - dice roll
- UUID generation
- File handling operations
  - create file
  - write file
  - append to file
  - read file
  - delete file
- Module exploration using `dir()`

## Project Structure

- `Moduler_Packager.py` — main interactive app

## How to Run

1. Open a terminal in the project folder.
2. Run:

```bash
python Moduler_Packager.py
```

3. Use the menu to choose an option.
